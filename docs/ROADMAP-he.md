# תוכנית העבודה של ביחד

## שלב 6 — מוזמנים ואישורי הגעה (גרסה 0.4 — הושלם)

- הזמנה למשפחה, לזוג או לאדם יחיד; ספירה נפרדת של הזמנות ושל אנשים.
- כמות מבוגרים וילדים, אישורי הגעה חלקיים, מי שלא יגיעו וטרם השיבו.
- צד, קבוצה, איש קשר, טלפון, צרכים תזונתיים והערות.
- חיפוש וסינון, סיכומי כמויות, עריכה ומחיקה עם אישור.
- שמירה מקומית ובענן, הרשאות, גרסאות, בדיקות ושדרוג נתונים 004.

## מה נשאר לגרסה הראשונה לשימוש יומיומי

1. **פגישות ותזכורות — תשתית הושלמה בגרסה 0.5:** ניהול פגישות, מועדים,
   אזורי זמן ומרכז תזכורות אישי, עם התראות מקומיות בהפעלה ידנית. עדיין יש לבדוק
   הרשאות וקבלת התראות בפועל באייפון. שינויים מרחוק מסתנכרנים כשפותחים את האפליקציה.
2. **השלמת פרטי החתונה:** עריכת שמות ותאריך לאחר ההגדרה הראשונית,
   והשלמת מסך הבית עם פגישות, תשלומים וספירה לאחור.
3. **מסמכים:** העלאת חוזים וקבלות לאחסון פרטי וקישור לכרטיס ספק או תשלום.
4. **השלמת ניהול החשבון:** שחזור סיסמה, מחיקת חשבון, התנהגות הנתונים בעת
   עזיבת אחד מבני הזוג, ומסכי פרטיות ותמיכה לפני הפצה לציבור.
5. **בדיקות בענן ובמכשירים:** חיבור Supabase בבעלותכם, בדיקה עם שני
   חשבונות ושני מכשירים, הרשאות והרשמה, סנכרון, ניתוקים והתנגשויות.
   בדיקות מסד הנתונים המקומיות אינן מחליפות בדיקות Supabase ו־Realtime.
6. **הפצה לאייפון:** חיבור חשבונות Expo ו־Apple שלכם, בנייה חתומה, בדיקת
   Face ID / Touch ID ושמירת ההתחברות, והרצה דרך TestFlight לפני הפצה.

אין כרגע התחייבות למועד הפצה. השלבים בענן ובאייפון תלויים בחיבור החשבונות
ובבדיקות בפועל. נתוני דמה או בדיקות בדפדפן אינם אישור שהבדיקות האלה הושלמו.

## הרחבות לאחר שהגרסה הבסיסית יציבה

- קישור אישי לאישור הגעה ללא התקנת האפליקציה.
- ייבוא וייצוא Excel.
- סידורי הושבה ולו״ז יום החתונה.
- השוואת הצעות ספקים מפורטת ומעקב החלטות משותפות.
- מעקב מתנות לאחר האירוע.

תזכורות ושליחת הודעות לאורחים הן יכולות שונות. אישורי ההגעה בגרסה 0.4
מתעדכנים ידנית בידי בני הזוג; לא נשלחות הודעות ולא נוצרים קישורים ציבוריים.
